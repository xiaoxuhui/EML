# 需求与测试用例：可视化函数定义

- **Status**: IMPLEMENTING
- **Date**: 2026-10-04

## 需求

1. 函数定义区改为“函数名（参数） = 表达式”的可视化编辑器，不再要求用户输入完整文本公式。
2. 用户输入函数名和以逗号分隔的参数名；名称与参数仍遵守现有标识符和参数数量限制。
3. 表达式区提供内置 `EML` 及已定义用户函数。把函数拖入空表达式或任一输入槽即可创建相应调用节点。
4. 参数名和数值栏数值可拖入调用节点的输入槽。参数保存为变量；数值保存为函数定义中的固定符号表达式。
5. 点击输入槽后，也可以点击函数、参数或数值完成同样的填入操作，便于鼠标拖动不便时使用。
6. 函数体必须完整才能保存；保存后仍在“函数应用”区新增独立调用行，已有文本定义和保存文件继续可用。
7. 已保存函数提供“编辑函数”。编辑会载入原来的表达式；保存修改时保留该函数应用行中已填入的参数值。

## 验收用例

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| VF01 | 输入 `f`、参数 `x`，将 EML 放入表达式区 | 显示 `f(x) = EML(□, □)`。 |
| VF02 | 将 x 拖到左槽、数值 1 拖到右槽 | 显示 `f(x) = EML(x, 1)`，可保存。 |
| VF03 | 已有 f 后定义 g，将 f 拖入 g 的表达式 | f 调用产生一个参数槽，保存 g 后可正常求值。 |
| VF04 | 把 `ln(2)` 拖入函数体 | 保存后的函数固定保留 `ln(2)`，不依赖数值栏项目仍存在。 |
| VF05 | 表达式或任何输入槽为空时保存 | 拒绝保存并说明未完成位置。 |
| VF06 | 在槽位被选中时依次点击函数、参数、数值 | 与对应拖放结果一致。 |
| VF07 | 导入旧文本定义 | 旧定义仍显示在函数应用区且可调用。 |
| VF08 | 编辑 `f(x) = EML(x, 1)` 为 `f(x) = EML(1, x)` | 表达式可重新搭建并保存，已有 f 输入槽的数值保留。 |
