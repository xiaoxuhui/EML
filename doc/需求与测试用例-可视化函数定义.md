# 需求与测试用例：可视化函数定义

- **Status**: IMPLEMENTING
- **Date**: 2026-10-04

## 需求

1. 函数定义区改为“函数名（参数） = 表达式”的可视化编辑器，不再要求用户输入完整文本公式。
2. 用户输入函数名和以逗号分隔的参数名；名称与参数仍遵守现有标识符和参数数量限制。
3. 表达式区提供内置 `EML` 及已定义用户函数。把函数拖入空表达式或任一输入槽即可创建相应调用节点。
4. 参数名和“数值栏”中的数值可拖入调用节点的输入槽。参数保存为变量；数值保存为函数定义中的固定符号表达式。
5. 点击输入槽后，也可以点击函数、参数或数值完成同样的填入操作，便于鼠标拖动不便时使用。
6. 函数体必须完整才能保存；保存后仍在“函数应用”区新增独立调用行，已有文本定义和保存文件继续可用。
7. 已保存函数提供“编辑函数”。编辑会载入原来的表达式；保存修改时保留该函数应用行中已填入的参数值。
8. 表达式编辑器支持右键删除：右键变量或固定数值会清空该输入槽；当函数节点的全部输入均为空槽时，右键该函数会删除函数节点本身。

## 验收用例

### 2026-10-29：定义与应用一致

函数表达式复用函数应用的名称、括号、灰色输入框和已填状态，空框显示真实参数名。
已填变量/数值也留在输入框中，可以直接拖入覆盖；数值采用与数值栏相同的 KaTeX 排版。
定义来源中的数值也采用数值栏的按钮与数学排版。
函数、变量、定义来源数值、数值栏数值共用同一指针拖放逻辑，支持鼠标与触摸。
保留点击来源再点槽位、右键删除、点击函数结构预览；不得因拖动后的click误写槽位。

UF01 比较定义/应用输入框的实际样式与尺寸；UF02 公式中的根式/分数/指数和数值栏数学DOM一致；
UF03 鼠标拖入与覆盖；UF04 真正触摸拖入（不是用tap冒充拖动）；
UF05 拖动取消/无效目标不写草稿或存档；UF06 既有结构预览、保存、取消、旧存档全回归。

UF07 超过拖动阈值后，函数/变量/数值有跟随鼠标或手指的可见预览，保留数学排版。
原来源变淡但不消失，不改变布局；预览不挡住投放命中。松手、取消或丢失指针捕获后清除预览及高亮。

### 2026-10-29：函数结构预览

点击表达式中的函数名，在定义区下方显示其只读展开结构，不进行数值计算。
显示实参以及被调用函数的函数体；替换形参后递归展开至 EML、变量、固定数值或空槽。
参数纵向排列，默认全部展开；不同分支的重复调用分别展开。空槽显示灰色方框。
点击嵌套函数只查看该节点；编辑、删除、取消后不得残留过期预览。
循环、缺失定义、参数数量错误和过大结构需明确提示，不无限递归。
查看预览和编辑未保存草稿不得写入缓存或修改已保存数值。

验收：FS01 拖入 EML 出现两个灰槽并可点击查看 X/Y；FS02 自定义函数形参替换；
FS03 多层和重复调用完整展开；FS04 点击子函数与键盘 Enter 查看；
FS05 填槽/右键删除实时更新，取消清空预览；FS06 桌面与移动无整页横向溢出；
FS07 预览不写缓存，旧存档可往返读取；FS08 循环、缺失、空槽与大小限制。
