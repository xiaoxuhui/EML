# 安卓打包需求与测试用例

- 版本：v1.2.0（APK 首发）
- 日期：2026-09-10
- 分支：`feat/android-apk`
- 上游版本：EML 计算台 v1.1.0

## 1. 需求目标

把 EML 计算台（纯静态网页应用）打包为可在安卓设备安装运行的 APK，
使其脱离浏览器与本地服务器，在手机/平板上离线使用。

### 1.1 目标设备

| 设备 | 系统 | 说明 |
|---|---|---|
| 华为 Mate 50 Pro | HarmonyOS 4.x（安卓兼容层） | 主力验证机，可安装 APK |
| 安卓平板 | Android 7.0+ | 大屏目标设备 |

> 说明：HarmonyOS 5.x/6.x（纯血鸿蒙）不支持 APK，本期**不做** HAP 包。

### 1.2 应用身份（已确认）

| 项 | 值 |
|---|---|
| 包名 applicationId | `com.xiaoxuhui.eml` |
| 应用显示名 | EML 计算台 |
| minSdk | 24（Android 7.0） |
| targetSdk | 34 |
| versionName | 1.2.0 |
| versionCode | 2 |
| 图标 | 自适应图标（AI 生成） |
| 签名 | 首版用 debug 签名 |

### 1.3 非目标（本期不做）

- 纯血鸿蒙 HAP 包
- 上架应用市场
- 原生功能（通知、分享、后台服务）
- 修改 EML 计算逻辑本身

## 2. 技术方案

极简 WebView 壳：

- 一个 `MainActivity`（Kotlin），内嵌 `WebView`
- 网页资源 `dist/eml-workbench.html` 放入 `app/src/main/assets/`
- 通过同步脚本从 `dist/` 拷贝，保证网页更新后 APK 内容自动跟上
- 构建走 GitHub Actions 云构建，产物挂到 Release

选择理由：零 node 依赖、契合仓库 dependency-free 调性、产物小（预计 1–3 MB）、
完全可控可复现。

## 4. 已知风险

| 风险 | 影响 | 应对 |
|---|---|---|
| Canvas/计算树在大网格下掉帧 | 平板体验 | 真机实测，必要时限制规模（下期） |
| 拖放交互在触摸端不触发 | 无法用拖拽赋值 | 已有「选中→点槽位」回退路径，可操作 |
| debug 签名有效期与换机冲突 | 长期分发受限 | 首版接受，后续生成正式 keystore |
| 鸿蒙 4.x 若升级到 5.x | APK 不可用 | 大版本需手动确认升级，暂不受影响 |
