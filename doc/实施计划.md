# EML 第一版本实施计划

## 目标

按照《需求与测试用例》和《设计文档》从零重写 EML 计算台，交付可在 Windows 浏览器中直接打开的单文件版本，并完成单元测试和真实浏览器交互测试。

## 执行原则

- 不修改或继续扩展旧版 `D:\soft\eml-workbench.html`。
- 新代码全部位于 `D:\soft\EML` Git 仓库。
- 计算核心、数据状态、持久化和界面交互分层实现。
- 每个阶段完成后运行对应测试，再进入下一阶段。
- 最终以 `dist/eml-workbench.html` 作为可直接打开的交付文件。

## 验收条件

- 《需求与测试用例》中的 U01-U17 全部通过。
- 《需求与测试用例》中的 I01-I14 全部通过。
- 页面首次启动只有固定值 `1`。
- 计算预览不会自动加入数值栏。
- 符号结果不自动显示为近似小数。
- 数值与公式均正确去重，完整计算树可查看。
- 保存、导入、刷新恢复以及删除保护均可正常工作。
- 最终 HTML 可直接打开运行，不依赖服务器。
