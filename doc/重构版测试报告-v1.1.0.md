# EML 1.1.0 重构版测试报告

## 重构目标

在不改变 `v1.0.0` 已确认数学结果、V2 保存格式和主要交互的前提下，降低公式引擎、计算树、导入校验和界面事件代码的维护风险。

## 结构变化

- `formula-rules.js` 从 631 行降至 102 行，只负责规则注册、递归化简和固定点迭代。
- 新增 `rules-transcendental.js`，承载指数、对数、欧拉公式和正弦规则。
- 新增 `rules-algebra.js`，承载整数、加减乘除和虚数单位规则。
- 新增 `expression-properties.js`，集中处理实数、正数、非零和纯虚数证明。
- 新增 `tree-controller.js`，从 `app.js` 抽离缩放、平移、滚轮和键盘事件。
- `app.js` 从 497 行降至 412 行。
- 测试按规则注册、校验和计算树拆为独立文件。

## 安全与性能

- 表达式限制为已知节点、已知常量和安全整数。
- 表达式最大深度 64，最大节点数 2,000。
- 导入文件最大 5 MiB、数值最大 2,000、公式最大 5,000。
- 推导表达式和化简步骤执行严格结构校验。
- 依赖循环改为线性图遍历检查，不再通过构建完整计算树判断。
- 计算树默认只展开 4 层，单次最多构建 800 个节点，最多展开 32 层。
- 化简达到 50 轮安全上限时显示提示并禁止添加当前结果。

## 自动测试

- 总计：81 项通过，0 项失败。
- 既有 71 项公式和状态回归全部通过。
- 新增规则注册表唯一性和说明完整性测试。
- 新增表达式严格校验、深度限制、畸形推导、循环依赖和文件大小测试。
- 新增计算树深度延迟、节点预算和无限制兼容行为测试。

## 浏览器回归

- 旧 V2 缓存成功恢复 92 个数值。
- 重构前当前公式结果 `sin(1)` 保持不变。
- 深层 `π` 计算树初始生成 68 个 DOM 节点和 6 条推导。
- 点击一次“展开更多”后生成 189 个 DOM 节点和 18 条推导。
- 缩放从 100% 调整至 90% 后变换正确。
- 固定高度计算树窗口、鼠标滚轮、拖动和 W/A/S/D 控制保留。

## 兼容性结论

- V2 保存格式未升级，旧缓存和导出文件继续兼容。
- 47 条公式规则编号和步骤记录保持不变。
- 单文件构建方式保持不变。
- `v1.0.0` 发布包和标签不受重构影响。
