# EML 公式覆盖审计

## 本轮结论

当前公式库已覆盖 EML 生成链中最常见的整数运算、同项消去、指数与对数反函数、欧拉公式及 `±iπ` 的复对数主值。复对数统一采用主值约定 `ln(-1)=iπ`，因此：

```text
ln(e^(a + iπ)) = a + iπ
ln(e^(a - iπ)) = a + iπ
```

其中 `a` 必须可证明为实数。不能证明定义域和分支安全时，表达式保持符号形式。

## 已覆盖

- 整数加、减、乘与负整数。
- 加减法零元、同项消去、相反数、嵌套同项消去。
- 乘法零元、单位元、负单位元和 `i²=-1`。
- `e^0`、`e^1`、`e^(±iπ)`。
- 正数域内 `e^(ln(a))=a`。
- 实数指数的 `ln(e^a)=a`。
- `a±iπ` 指数的复对数主值。
- `ln(1)`、`ln(e)`、`ln(-1)` 主值。

## 暂不自动化简

- 一般复数指数的 `ln(e^z)`，因为结果需要按虚部对 `2π` 取主值分支。
- `ln(ab)=ln(a)+ln(b)`、`ln(a/b)=ln(a)-ln(b)`，因为复数域存在分支问题。
- 一般根式乘除、平方与绝对值规则，直到根式定义域和主值规则确定。
- 任意多项式展开、因式分解和同类项收集。当前版本不是通用计算机代数系统。

## 三角函数阶段

三角函数不能只增加显示规则。开始实现前需要先扩展表达式结构：

1. 增加有理数或除法节点，以表示 `π/2`、`π/3`、`√2/2`。
2. 增加 `sin`、`cos`、`tan` 节点及符号渲染、近似计算、保存校验。
3. 第一批规则覆盖 `0`、`π/2`、`π`、常用特殊角和奇偶性。
4. 增加周期规则与 `sin²(x)+cos²(x)=1`，并防止重写循环。
5. 再接入欧拉公式 `e^(ix)=cos(x)+i sin(x)`；必须规定转换方向，不能双向反复重写。
6. 为 `tan(x)` 增加定义域检查，不能在 `cos(x)=0` 时化简为除法结果。

每条新规则继续要求正例、反例、组合化简和真实页面计算树测试。
