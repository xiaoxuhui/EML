# EML 公式覆盖审计

## 本轮结论

当前公式库已覆盖 EML 生成链中最常见的整数运算、同项消去、指数与对数反函数及欧拉公式。根据项目约定，明确写成 `ln(e^z)` 的表达式采用形式化反函数规则，保留原指数：

```text
ln(e^(a + iπ)) = a + iπ
ln(e^(a - iπ)) = a - iπ
```

该约定优先保留表达式的生成结构，不对 `z` 施加实数条件。它不是复对数主值恒等式；直接输入 `ln(-1)` 时仍使用项目约定 `ln(-1)=iπ`。

## 已覆盖

- 整数加、减、乘与负整数。
- 加减法零元、同项消去、相反数、嵌套同项消去。
- 乘法零元、单位元、负单位元和 `i²=-1`。
- `e^0`、`e^1`、`e^(±iπ)`、`e^(±iπ/2)`。
- 任意符号指数的形式化反函数 `ln(e^a)=a`。
- 形式化反函数 `e^(ln(a))=a`，参数已明确化简为 `0` 时除外。
- 非零判定覆盖“非零纯虚数与实数的加减”，例如 `i-ln(4)`。
- 非零参数的指数差 `e^(a-ln(b))=e^a/b`。
- 非零参数的负对数指数 `e^(-ln(b))=1/b`。
- 形式化对数和指数 `e^(ln(a)+ln(b))=ab`，明确的零参数除外。
- 指数与对数和 `e^(a+ln(b))=b×e^a`，明确的零参数除外；结合 `e^(1/2)=√(e)` 可得到 `e^(1/2+ln(2))=2×√(e)`。
- 半对数指数 `e^(ln(a)/2)=√(a)`，同时识别 `ln(a)×(1/2)` 结构，明确的零参数除外。
- 负因子乘法与 `i(ia)=-a` 的复数乘法整理。
- 正数分母下的 `ln(a)-ln(b)=ln(a/b)`。
- 非零分母下的定向形式化规则 `ln(e^a/b)=a-ln(b)`，避免与对数合并规则循环。
- 非零参数的形式化倒数规则 `ln(1/a)=-ln(a)`。
- 结构化除法、整除、除以一和非零同项相除。
- 虚数单位分母 `a/i=-ai` 和 `a/(-i)=ai`，例如 `2/(-i)=2i`。
- `sin` 表达式节点、符号显示、复数近似计算和欧拉正弦公式 `(e^(ia)-e^(-ia))/(2i)=sin(a)`。
- `ln(1)`、`ln(e)`、`ln(-1)` 主值。

## 暂不自动化简

- 复对数主值的自动换支；当前项目选择保留 `ln(e^z)` 中明确写出的指数。
- `ln(ab)=ln(a)+ln(b)`、`ln(a/b)=ln(a)-ln(b)`，因为复数域存在分支问题。
- 一般根式乘除、平方与绝对值规则，直到根式定义域和主值规则确定。
- 任意多项式展开、因式分解和同类项收集。当前版本不是通用计算机代数系统。

## 三角函数阶段

三角函数阶段已经启动，`sin` 节点和第一条欧拉正弦规则已完成。后续仍需：

1. 已增加除法节点；后续补充分数约分和统一符号规范，以稳定表示 `π/2`、`π/3`、`√2/2`。
2. 增加 `cos`、`tan` 节点及符号渲染、近似计算、保存校验。
3. 第一批规则覆盖 `0`、`π/2`、`π`、常用特殊角和奇偶性。
4. 增加周期规则与 `sin²(x)+cos²(x)=1`，并防止重写循环。
5. 再接入欧拉公式 `e^(ix)=cos(x)+i sin(x)`；必须规定转换方向，不能双向反复重写。
6. 为 `tan(x)` 增加定义域检查，不能在 `cos(x)=0` 时化简为除法结果。

每条新规则继续要求正例、反例、组合化简和真实页面计算树测试。
