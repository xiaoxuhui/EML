## 提交纪律

- 每个阶段一个 commit，前缀 `feat` / `fix` / `docs` / `ci` / `release`
- 每阶段结束跑 `node --test tests/*.test.js`（当前 90 项全过）
- 不在 `feat/android-apk` 上修改 EML 主应用源码（主应用改动放 `feat/touch-responsive`）

## 环境注意事项（本机已确认）

- 无 JDK / Android SDK / Gradle → 不本机构建，走 GitHub Actions
- C 盘空间紧张 → 不安装安卓工具链
- git 嵌套分支在本环境需写入 `packed-refs`（`git branch feat/xxx` 会静默失败）
- bash 环境下 `git checkout` 对 `.git` 有破坏性 → 一律用 `symbolic-ref` + `reset --mixed` 切分支
- gradlew 等 shell 脚本须以 LF 入库（`.gitattributes` 已约束），否则 Linux 构建失败
