## 单元测试

《需求与测试用例》中的 U01-U17 全部通过，另外增加并通过：

- 被其他公式引用的数值不允许删除。
- 无效 JSON 和结构不完整的导入数据不能通过校验。
- `e - ln(e^(e))` 可继续化简为 `0`，并保留两步规则记录。
- `ln(e^i)` 不会套用仅适用于实数指数的规则。
- 嵌套公式 `e - ln(e^(e - ln(e - 1)))` 可继续化简为 `ln(e - 1)`。
- `e^(ln(e - 1)) - e` 可使用正数域反函数和减法消去规则化简为 `-1`。
- 整数加、减、乘会直接计算，`1 - -1` 可继续化简为 `2`。
- `ln(e^z)` 按项目约定使用形式化反函数，`e - ln(e^(e - iπ))` 化简为 `iπ`。
- 基础代数组合审计覆盖双重负号、相反数、嵌套加减、负单位元、`i²` 和 `e^(-iπ)`。
- `e^(ln(ln(iπ))) - ln(2)` 可化简为 `ln(iπ / 2)`，除法表达式可保存并从缓存恢复。
- 欧拉特殊角 `e^(iπ/2)=i` 和 `e^(-iπ/2)=-i` 均可直接化简。
- 指数差 `e^(a-ln(b))` 可在 `b≠0` 时化为 `e^a/b`，本例得到 `i/2`。
- `ln(e^a/b)` 可在 `b>0` 时定向化为 `a-ln(b)`，避免规则循环；本例最终得到 `ln(2)`。
- 非零判断可识别带确定非零虚部的复数，`e^(ln(i-ln(4)))` 化简为 `i-ln(4)`，同时保留 `ln(0)` 保护。
- 负对数指数 `e^(-ln(b))` 可在 `b≠0` 时化为 `1/b`，本例得到 `1/4`。
- 指数商对数的形式化规则支持可证明非零的复数分母，`e-ln(e^e/(e-i))` 化简为 `ln(e-i)`。

## 布局与可用性检查

- 桌面页面没有控件重叠或页面级横向滚动。
- 390×844 窄屏下结果和“添加”按钮自动换行并保持可见。
- 长表达式允许换行，不覆盖删除按钮。
- 删除按钮与数值按钮分离，点击短数值不会误触删除。
- 除拖放外，还支持先选择数值再点击 x 或 y，便于键盘和触摸操作。

## 测试中修复的问题

1. 原先短数值的删除按钮覆盖卡片中央，点击 `π` 可能误删；已改为右侧独立删除按钮。
2. 原先窄屏计算行需要横向滚动才能看到结果；已改为自动换行。
3. 原生 HTML 拖放在不同浏览器测试接口中表现不一致；已改为统一指针拖动，并在 Chrome 中验证成功。
