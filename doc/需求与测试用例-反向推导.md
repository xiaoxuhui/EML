# 需求与测试用例 — 反向推导展示（feature: derivation-trace）

- **Status**：VERIFIED（2026-09-28 回填；单测 TR01–TR13 与浏览器 IR01–IR04 均通过）
- **Approved**：2026-09-28（肖工一次性授权，无人值守执行）
- **Type**：feature
- **版本**：v1.3.0

## 一、需求原文与范围界定

> 肖工原话：「任意给定一个公式，请反向把推导过程展示出来」

**范围界定（审查结论 D-23）**：

「任意给定一个公式」在本版取**「用户在数值栏中任选一个已有数值」**，
工作台展示**从初始值 `1` 到该数值的完整推导链**——即「它是怎么被一步步造出来的」。

**本版不做**：自由文本公式输入。理由是设计文档明确第一版不提供公式文本框，
且自由输入需要一整套解析器与错误处理，属独立议题。

## 二、What（做什么）

1. 数值栏选中任意数值后，「公式详情」面板新增**「推导过程」**板块。
2. 该板块按**建造顺序**（依赖在前）线性列出从初始值 `1` 到目标数值的每一步。
3. 每步展示：序号、该步得到的值、`EML(x, y)` 的代入形式、以及该步的化简过程。
4. 一旦某个值在前面已经推出来过，后续步骤**引用步号**而非重复展开。
5. 目标已经是最初的 `1` 时，明确显示「初始值，无需推导」。

## 三、验收标准（Definition of Done）

> 全部于 2026-09-28 回填。证据：`tests/derivation-trace.test.js`（TR01–TR13，随全量 111/111 通过）
> 与 `.e2e-tmp/verify-derivation-trace.cjs` 浏览器实测（IR01–IR04，16/16 断言、控制台无 error）。

- [x] 选中任一数值都能得到一条**拓扑有序**（每个值的输入都在它之前）的推导链 ← TR04
- [x] 推导链的**最后一步一定是选中的目标值** ← TR06
- [x] 复用的值以「第 N 步」形式引用，不重复展开 ← TR05 / TR12 / IR03
- [x] 每步的化简过程可查看（与计算树里的信息同源） ← TR11
- [x] 目标为初始值 `1` 时给出明确空态 ← TR01 / IR01
- [x] 规模上限可控：超过步数/节点预算时**明确标注被截断**，不静默丢弃 ← TR07
- [x] 页面真实可交互（浏览器验证通过） ← IR01–IR04
- [x] 单元测试覆盖全部逻辑用例，且**不改变原有行为** ← TR01–TR13 / TR10（纯函数）

## 四、测试用例

### 逻辑用例（TR 系列）

| 编号 | 场景 | 输入 | 期望 |
|---|---|---|---|
| TR01 | 初始值 | 选中 `1` | 单步链，标明是初始值；不报错 |
| TR02 | 单层推导 | `EML(1,1) → e` | 两步：`1`（初始）→ `e`（EML(1,1)） |
| TR03 | 多层链 | `1 → e → e-1` | 三步，顺序为 `1`、`e`、`e - 1` |
| TR04 | 拓扑序 | 任意多值图 | 每个步骤引用的输入，其步号必小于当前步号 |
| TR05 | 复用引用 | `EML(e, e)`（e 已推导） | `e` 只展开一次，第二处标为引用步号 |
| TR06 | 末步即目标 | 任意选中值 | `steps[steps.length-1].valueId === 目标` |
| TR07 | 步数预算 | `maxSteps` 设得很小 | 返回 `truncated: true` 且 `reason === "step-limit"`，不抛异常 |
| TR08 | 多来源取值 | 一个值有多条 derivationIds | 取第一条，并报告其余来源数量 |
| TR09 | 缺失值 | 不存在的 valueId | 返回 `ok: false`，不抛异常 |
| TR10 | 不改变原状态 | 调用前后 | 传入的 `state` 对象深度不变（纯函数） |
| TR11 | 化简过程同源 | 含 rewriteSteps 的推导 | 步骤中携带与原 derivation 相同的化简步骤内容 |
| TR12 | 目标为复用点 | 目标值前面已出现过 | 不重复追加，正确引用首次出现的步号 |

### 交互用例（IR 系列，真实浏览器）

| 编号 | 场景 | 期望 |
|---|---|---|
| IR01 | 选中 `1` | 显示空态文案，不显示步骤列表 |
| IR02 | 推导一个值后选中它 | 「推导过程」按序列出 `1 → ... → 目标` |
| IR03 | 复用场景 | 页面出现「第 N 步」引用文案 |
| IR04 | 控制台 | 全程无 error |

## 五、明确的非目标

- 不做自由文本公式解析与输入。
- 不做「反向求解」式的代数反演（不是求「哪些输入能得出该值」）。
- 不改变计算树板块的既有行为。
- 不改动数值去重与存储格式（保证旧存档可继续导入）。
