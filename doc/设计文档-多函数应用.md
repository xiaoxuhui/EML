# 设计文档：多函数应用

- **Status**: APPROVED
- **Date**: 2026-10-03

## 模型

函数应用由内置 EML 与用户函数并列组成。用户函数状态为：

```text
customFunctions: [{ id, definitionText, inputValueIds }]
```

`id` 是稳定本地标识；公式来源继续保存 `functionDefinition` 与参数输入 ID，因此删除定义不会破坏既有推导。`customFunction` 是旧格式兼容字段，仅在导入时读取并迁移，不再写入新状态。

## 交互

“函数应用”从 EML 行开始，随后按定义顺序显示每个用户函数。每行用 `function:<id>:<parameterIndex>` 标识输入槽位，避免函数之间覆盖输入状态。定义区提交后添加一行；删除定义仅删除该函数的应用行和定义列表项。

## 验证

单元测试覆盖多定义、独立输入、去重和迁移。静态界面测试断言 EML 与多个函数处于同一个应用区域，定义区不承载计算行。浏览器测试补测点击/拖放、添加和删除定义。
