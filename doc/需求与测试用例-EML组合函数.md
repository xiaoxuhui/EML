# EML 组合函数需求与测试用例

- **Status**: PENDING
- **Approved**: 2026-10-03 用户确认“函数仍使用 EML 嵌套形式，并直接放在计算区下方”
- **Type**: feature

## 目标

在现有 `EML(x, y)` 计算行下方提供一个内嵌的 EML 组合函数界面。用户以 `F(x, y, z) = EML(EML(x, y), z)` 形式定义函数，通过数值栏拖放或点击填入多个参数，预览结果并主动添加至数值栏。

## 功能规则

1. 函数定义只接受函数名、1 至 6 个唯一参数名、`EML(...)`、逗号和括号；不提供任意四则运算文本输入。
2. 函数体只能引用已声明参数，且每个 `EML` 调用必须恰有两个参数。
3. 定义有效后，根据参数数量显示对应数量的输入槽位；槽位与原 EML 的 x、y 一样支持拖放、点击选中值填入和覆盖。
4. 参数未填满、定义无效、计算无效或化简达到安全上限时，不允许添加。
5. 点击“添加”后，结果进入原数值栏；数值去重、公式去重、删除引用保护、直接公式、推导过程和完整计算树均继续生效。
6. 自定义来源显示函数调用，例如 `F(1, 1, 1) = e^(e) - 1`，并记录函数定义和所有输入数值。
7. 函数定义和已填入的参数随浏览器缓存与 JSON 保存/导入保留。旧 V2 保存文件没有此字段时仍可导入，组合函数恢复为空定义。
8. 组合函数界面必须直接位于“计算”区域内的原 EML 行之后，不使用弹窗、新窗口或独立页面。

## 非目标

- 第一版不提供多个自定义函数的列表或切换器。
- 第一版不解析 `+`、`-`、`×`、`/`、`^` 等自由文本数学表达式。
- 第一版不允许自定义函数相互调用；嵌套只发生在内置 `EML` 调用之间。

## 验收用例

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| UCF01 | 解析 `F(x, y, z) = EML(EML(x, y), z)` | 得到名称 `F`、三个参数和嵌套 EML 结构 |
| UCF02 | 解析 `F(x, x) = EML(x, x)` | 因重复参数而拒绝 |
| UCF03 | 解析 `F(x) = EML(x)` | 因 EML 参数不足而拒绝 |
| UCF04 | 解析 `F(x) = EML(x, z)` | 因未声明参数 `z` 而拒绝 |
| UCF05 | 使用 `F(x, y, z) = EML(EML(x, y), z)`，输入 `1, 1, 1` | 预览为 `e - 1`，直接公式为 `F(1, 1, 1) = e - 1` |
| UCF06 | 添加组合函数结果 | 结果进入数值栏，并保存 `EML_COMPOSITION` 来源和三个输入引用 |
| UCF07 | 重复添加相同定义和输入 | 不重复增加公式来源 |
| UCF08 | 被组合函数引用的数值尝试删除 | 阻止删除 |
| UCF09 | 旧 V2 保存数据导入 | 正常导入，组合函数为空定义 |
| ICF01 | 界面位置 | 组合函数区域紧跟原 EML 计算行，不出现弹窗或新页面 |
| ICF02 | 拖放与点击填入 | 三个动态槽位均可填入、覆盖并实时更新结果 |
| ICF03 | 添加流程 | 结果通过“添加”进入原数值栏，点击结果后能看到来源和计算树 |
| ICF04 | 窄屏 | 长函数定义、动态槽位和添加按钮不重叠、不产生页面横向溢出 |
