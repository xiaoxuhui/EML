# EML 计算台：需求与测试用例

## 文档状态

- 状态：讨论中
- 当前阶段：梳理功能边界与验收标准；后续将按本文件重写页面，不沿用旧页面逻辑继续重构

## 一、产品需求

### 1. 计算区

页面顶部显示：`EML(x, y) = ?`。

- 用户可从下方数值栏拖动任意数字或表达式到 `x`、`y`。
- `x`、`y` 不需要先清空；拖入新值时直接覆盖原值。
- 当 `x`、`y` 都有值时，`?` 自动显示计算结果。
- 结果区旁提供“添加”按钮。只有点击“添加”后，当前结果才进入数值栏。
- 每个加入数值栏的结果需要记录其推导公式。

### 2. 数值栏

- 首次启动时，数值栏只有 `1`。
- 初始值 `1` 为固定项目，不允许删除。
- 后续数值只能由计算区的“添加”按钮加入。
- 数值栏应按数学数值去重：相同的值只能保留一个项目。
- 公式来源也应去重：同一条公式只记录一次。
- 同一个数值允许保留多条不同的公式来源。
- 数值项目应可拖动回 `x`、`y` 继续计算。
- 每个项目应能查看其符号值与公式来源。
- 删除项目、添加项目、清空列表后，数据应立即写入本地缓存。

### 3. 符号计算与公式库

计算应优先保留和化简符号表达式；内部可保存数值近似值用于计算与去重，但不应把近似值作为主要显示内容。

首批内置公式：

- `e^1 = e`
- `e^0 = 1`
- `ln(1) = 0`
- `ln(e) = 1`
- `e^(iπ) = -1`

可逐步扩展：常见指数、对数、复数与根式规则。

### 4. 显示规则

- `ln`、`i`、`e`、`π`、根号应保留符号形式，不自动显示为小数。
- 结果应尽量化简。例如：`EML(1, 1) = e`。
- 无法继续化简时，显示公式形式。例如：`e^(π) - ln(ln2)`。
- 非法表达式应给出中文错误提示，不得加入数值栏。

### 5. 保存与恢复

- 点击“保存列表”时导出包含数值、符号表达式和公式来源的文件。
- 导入同类文件时恢复完整列表。
- 页面启动时优先从浏览器本地缓存恢复。

### 6. 公式详情区

- 页面最下方新增“公式详情”区域。
- 用户点击数值栏中的任意项目后，该项目进入选中状态。
- 公式详情区显示该数值的直接公式，例如 `EML(1, 1) = e`。
- 公式详情区同时显示该数值的完整计算树，展开到所用输入值及其公式来源。
- 若同一数值有多个不同公式来源，详情区应全部展示，并保持公式去重。
- 未选中项目时，详情区显示空状态提示。

## 二、待确认决策

当不同公式得到同一个数学数值时，数值栏只保留一个项目。该项目保留全部不同的公式来源，例如 `e` 同时记录 `e^1` 与 `EML(1, 1)`；相同公式不重复保存。

## 三、单元测试用例

| 编号 | 类别 | 输入/操作 | 期望结果 |
| --- | --- | --- | --- |
| U01 | 基础计算 | `EML(1, 1)` | 结果为 `e` |
| U02 | 指数化简 | `EML(0, 1)` | 结果为 `1` |
| U03 | 对数化简 | `EML(1, e)` | 结果为 `e - 1` |
| U04 | 欧拉公式 | `EML(iπ, 1)` | 结果为 `-1` |
| U05 | 符号保留 | `EML(π, ln2)` | 显示 `e^(π) - ln(ln2)`，不出现近似小数 |
| U06 | 复数保留 | `EML(i, 1)` | 显示 `e^(i)`，不转小数 |
| U07 | 根式保留 | 输入含 `√2` | 界面显示 `√2`，不显示 `1.414...` |
| U08 | 去重 | 连续添加两次 `EML(1, 1)` | 数值栏只有一个 `e` |
| U09 | 公式去重 | 连续添加同一条 `EML(1, 1)` | `e` 只保留一条该公式来源 |
| U10 | 多公式记录 | 两条不同公式均得到 `e` | 数值栏只有一个 `e`，但保留两条不同公式来源 |
| U11 | 公式详情 | 选中数值栏中的 `e` | 底部完整显示 `e` 的全部 EML 公式来源 |
| U12 | 切换选中项 | 依次选中两个不同数值 | 公式详情切换为当前选中数值的公式 |
| U13 | 初始值保护 | 尝试删除初始值 `1` | `1` 保留，删除操作不可用 |
| U14 | 完整计算树 | 选中由多个步骤得到的项目 | 详情显示直接公式及逐层展开的输入来源 |
| U15 | 覆盖输入 | x 已为 `1`，再放入 `π` | x 显示 `π`，结果按新 x 更新 |
| U16 | 非法输入 | y 为 `0` | 显示 `ln(0)` 未定义，不能添加 |
| U17 | 保存导入 | 保存后重新打开或导入 | 数值、符号显示与公式记录恢复 |

## 四、交互测试用例

| 编号 | 操作步骤 | 验收标准 |
| --- | --- | --- |
| I01 | 首次打开页面 | 数值栏只显示 `1`；结果为 `?`；“添加”按钮不可用 |
| I02 | 将 `1` 拖到 x | x 显示 `1`；结果仍为 `?` |
| I03 | 将 `1` 拖到 y | 结果显示 `e` 和推导公式；数值栏仍只有 `1` |
| I04 | 点击“添加” | 数值栏新增可拖动的 `e` |
| I05 | 再次点击“添加” | 不新增第二个 `e`；公式来源按最终规则处理 |
| I06 | 将 `π` 拖到 x | x 被直接覆盖；结果立即更新 |
| I07 | 以 `iπ` 和 `1` 计算 | 显示 `-1`，且可以添加 |
| I08 | 选中数值栏中的一个项目 | 底部公式详情区完整显示该项目的全部公式来源 |
| I09 | 选中另一个项目 | 底部公式详情区切换到新项目的公式来源 |
| I10 | 尝试删除初始值 `1` | `1` 无删除按钮或删除操作被阻止 |
| I11 | 选中多步计算得到的项目 | 详情区同时显示直接公式和完整计算树 |
| I12 | 删除一个非初始项目后刷新页面 | 被删除项目不应恢复 |
| I13 | 保存、关闭、重新打开 | 列表和公式来源恢复 |
| I14 | 导入格式错误的文件 | 显示中文错误提示，现有列表不被清空 |
