# 需求与测试用例：多函数应用

- **Status**: APPROVED
- **Date**: 2026-10-03
- **Change**: 将 EML 和用户定义函数统一为可应用函数；支持多个用户定义函数。

## 需求

1. `EML(x, y)` 是内置函数，属于“函数应用”区域，不能删除。
2. 用户可保存多个函数定义，例如 `f(x) = EML(x, 1)` 与 `g(x, y) = EML(EML(x, y), 1)`；函数定义允许嵌套 `EML(...)`、定义的参数和基础常量 `0`、`1`、`e`、`i`、`π`。
3. 每个已定义函数在“函数应用”区域拥有独立应用行，参数槽位、结果预览与“添加”行为和 EML 一致。
4. “函数定义”区域仅用于新增、查看和删除用户函数；同名定义被拒绝，避免覆盖历史公式来源。
5. 删除函数定义不删除已经加入数值栏的结果；这些结果继续保存直接公式与完整计算树。
6. 旧保存文件中的单个 `customFunction` 自动迁移为一项用户函数；缺少该字段的旧 V2 文件仍可导入。
7. 新函数可调用已经保存的用户函数，例如先定义 `f(x) = EML(x, 1)`，再定义 `g(x) = f(x)`；调用函数会在求值时展开。未定义函数与循环引用必须拒绝。

## 验收用例

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| MF01 | 初始页面 | 函数应用含 EML 行；定义列表为空。 |
| MF02 | 定义 `f(x) = EML(x, 1)` | 新增 f 应用行，显示 `f(□) = ?`。 |
| MF03 | 定义 f 与 g | 两个应用行同时存在且参数状态相互独立。 |
| MF04 | 对 f 填入 1 并添加 | 结果 e 加入数值栏，直接公式为 `f(1) = e`。 |
| MF05 | 尝试重复定义 f | 定义被拒绝，已有 f 保持不变。 |
| MF06 | 删除 f 定义 | f 应用行和定义列表项移除，已添加的 f 结果与其推导仍可查看。 |
| MF07 | 导入旧单函数保存文件 | 单函数迁移到函数列表且可继续应用。 |
| MF08 | 导入旧 V2 无函数文件 | 导入成功，函数定义列表为空。 |
| MF09 | 先定义 f，再定义 `g(x) = f(x)` | g 保存成功；g(1) 的结果为 e，且保留展开后的计算树。 |
| MF10 | 定义 `g(x) = h(x)` 或自引用 `g(x) = g(x)` | 保存被拒绝，并显示未定义或循环引用错误。 |
